# 助手控制板通信协议测试用例

## 测试环境信息
- 目标主机: 10.0.5.210
- 账户: root
- 密码: 123
- 环境: Linux Debian
- 串口路径: /dev/ttyS4
- 波特率: 115200
- 数据位: 8位
- 校验位: 无
- 停止位: 1位

## 测试规则
1. **测试范围**: 覆盖除IAP升级功能和底层MCU主动上报的协议外其他所有的通讯协议字段和设定值
2. **超时判定**: 3秒内未响应则判定为测试失败
3. **失败判定**: 
   - 返回字段不符合协议规范
   - 返回超时（3秒未响应）
4. **测试类型**: 仅作协议完整性测试，不包含硬件响应和外部功能响应

## 通用帧格式
| 字段 | 长度(字节) | 说明 |
|------|------------|------|
| 帧头 | 1 | 0xAE，帧起始标志 |
| 长度高字节 | 1 | 0x00，帧长度高字节 |
| 长度低字节 | 1 | 从帧头到帧尾的总长度 |
| 命令码 | 1 | 0xAx，命令/识别码 |
| 有效数据区 | N | 命令相关数据 |
| 校验位 | 1 | 从帧头到有效数据区的所有字节求和取低8位 |
| 帧尾 | 1 | 0xFE，帧结束标志 |

## 附录：校验和计算方法

校验和计算方法：从帧头（0xAE）开始，到有效数据区的最后一个字节为止，所有字节求和后取低8位。

**示例计算：**
以心跳帧（AE 00 07 A0 12 FE）为例：
```
校验和 = (0xAE + 0x00 + 0x07 + 0xA0 + 0x12) & 0xFF
       = (174 + 0 + 7 + 160 + 18) & 0xFF
       = 359 & 0xFF
       = 0x67
```
完整帧为：AE 00 07 A0 12 67 FE
